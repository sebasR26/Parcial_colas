5
Supermercado — Cajas especiales
Un supermercado tiene cajas de atención especial.
Los clientes forman filas y pueden necesitar atención por diferentes motivos.
Un cliente puede abandonar la fila, cambiar de caja o ser atendido por otra caja disponible.
El sistema debe controlar el movimiento de los clientes.
